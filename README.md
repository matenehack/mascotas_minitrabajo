# Refugio de mascotas

Página de una sola vista con diseño verde y crema, HTML5, CSS externo y JavaScript.

## Uso

Descarga el repositorio y abre `index.html` en un navegador. Mantén las carpetas `img` y `media` junto al archivo.

Las fuentes de Google, el video de YouTube y el enlace a WUF requieren internet. Los datos de contacto son ejemplos de la consigna.
